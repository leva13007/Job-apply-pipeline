# brief.md — job_pipeline

Problem: Ручний пошук вакансій + підготовка CV/cover letter + подача займає ~2 години на 10 вакансій і дає незадовільну якість релевантності.

Roles: user (єдиний користувач/job seeker) — система збирає його дані при першому запуску (онбординг) в base_cv.md і user_info.md, дозапитує лише те, чого там нема
Goal: за командою "подайся на N вакансій" система виконує N релевантних подач на LinkedIn без ручного втручання(там де можливо, якщо наприклад не виходить завантажити CV в форму - запитує користувача зробити цей крок і продовжує далі в автоматичному режимі)
Metrics: 10 релевантних подач за ≤1 годину (без жорсткого ліміту часу); response rate від рекрутерів — TBD (буде виміряно пізніше)

Out of scope (v1): інші майданчики окрім LinkedIn (Indeed, Glassdoor, djinni, dou.ua) як джерело пошуку; планування подач на тиждень/місяць; автовідповіді рекрутерам у LinkedIn; підготовка до співбесід; аналітика/дашборд по подачах

Glossary:
  Easy Apply — подача вакансії напряму через LinkedIn без переходу на сайт компанії
  External Apply — подача, що веде на сторонній сайт/ATS поза LinkedIn
  ATS (Applicant Tracking System) — система обробки заявок компанії (Greenhouse, Lever, Workday тощо), куди може вести External Apply; при виявленні фіксується як потенційний ресурс для прямого пошуку вакансій у майбутньому
  base_cv.md — базовий, майданчико-незалежний профіль користувача (досвід, навички, освіта)
  user_info.md — розширена інфа про користувача (переваги, обмеження, контакти, відповіді на типові анкетні питання)
  релевантна подача — вакансія, що відповідає заданим параметрам користувача (стек, рівень, локація/remote, зарплата тощо)
  tailored CV — CV, згенероване/адаптоване під конкретну вакансію на основі base_cv.md
  cover letter — супровідний лист, генерується лише якщо вакансія цього вимагає
  search criteria / filter profile — набір параметрів пошуку вакансій (посада, стек, локація, seniority тощо)
  application status — стан поданої заявки (submitted, viewed, rejected, interview, no response)
  application log / tracker — реєстр усіх поданих заявок зі статусами (v1)
  recruiter contact — наявність прямого контакту рекрутера у вакансії (підвищує пріоритет подачі)
  submission batch — задана користувачем кількість подач за один запуск (напр. "подайся на 10 вакансій")
  form-fill — автоматичне заповнення кастомних анкет на сайті ATS/компанії
  duplicate detection — перевірка, щоб не подаватись повторно на ту саму вакансію/компанію

Constraints: дедлайну немає; технічний стек ще не обрано; мова CV та cover letter — англійська (ринок UK, згодом можливо Північна Америка)
